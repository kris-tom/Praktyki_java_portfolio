# Portfolio - Praktyki Zawodowe (Java / Spring Boot)

Repozytorium zawiera zbiór projektów zrealizowanych w ramach praktyk zawodowych na stanowisku programisty. Przedstawiają one mój progres nauki – od podstawowych konstrukcji języka Java, po tworzenie komunikujących się ze sobą aplikacji sieciowych.

## Główne projekty: Task 14 i Task 15
Najważniejszym elementem repozytorium jest implementacja architektury klient-serwer z wykorzystaniem frameworka Spring Boot. 

* **Task 14 (REST API Server):** Główne API służące do zarządzania bazą zasobów. 
  * Wdrożono wbudowaną, relacyjną bazę danych **HSQLDB**.
  * Zabezpieczono dostęp do endpointów za pomocą autoryzacji opartej na kluczu API (**API Key / Spring Security**).
  * Wygenerowano interaktywną dokumentację za pomocą **Swagger UI / OpenAPI**.
* **Task 15 (REST Client):** Dedykowana aplikacja kliencka, która płynnie łączy się z serwerem (Task 14) za pomocą narzędzia `RestClient`, automatycznie przekazując wymagane nagłówki autoryzacyjne.

## Pozostałe zagadnienia w repozytorium:
* **Task 01 - 13 oraz Podstawy Javy:** Projekty wprowadzające, obrazujące naukę algorytmiki, podstaw programowania obiektowego, operacji na łańcuchach znaków (String) oraz wstęp do frameworka Spring.
* **Technologie XML:** Praca ze strukturami danych oraz tworzenie schematów walidacyjnych **XSD**.
